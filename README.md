# Landing Page v2

A responsive personal portfolio website designed to showcase UI/UX design, product design, and visual communication projects.

Built with a lightweight frontend stack using HTML, Tailwind CSS, and Vanilla JavaScript — without a frontend framework or build tool.

---

## ✨ Overview

This project is a personal portfolio website created to present selected design work and professional experience in a clean, interactive, and responsive interface.

The portfolio focuses on:

- UI/UX & Product Design
- Mobile & Web Applications
- Enterprise Digital Products
- Visual Communication & Promotional Design
- Infographics & Digital Campaigns

The website is designed to balance **case-study storytelling** with a visual gallery experience for projects that contain a large collection of design assets.

---

## 🎯 Features

### Project Showcase
- Dynamic project listing
- Project category filtering
- Project detail view
- Previous / next project navigation
- Responsive project layouts

### Visual Design Gallery
- Masonry-style image gallery
- Category-based filtering
- Hover interaction with project information
- Image lightbox preview
- Responsive gallery layout
- Support for large collections of visual assets

### UI/UX Case Studies
Each selected project can present:

- Project overview
- Role & responsibilities
- Tools & methods
- Design contribution
- Screens & mockups
- Interactive prototypes

## 🎨 Visual Communication & Promotional Design

The visual design section uses a dedicated masonry gallery to showcase multiple design outputs without turning every asset into a separate project.

Designs are grouped into:

- **Social Media & Digital Campaigns**
- **Website & Digital Banners**
- **Email & Direct Communication**
- **Infographics & Data Communication**
- **Product & Service Promotion**
- **Internal Communication & Corporate Events**
- **Visual Assets & Supporting Materials**

Users can view all designs by default or filter the gallery by category.
